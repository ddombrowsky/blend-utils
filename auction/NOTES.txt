## automated auction bot

source:
    https://github.com/script3/auctioneer-bot

docker:
    docker pull script3/auctioneer-bot:latest

config.json:
* `defaultProfitPct` is from 0.00 to 1.00, 0.1 = 10%.
* `minHealthFactor` 0 to inf, 1.1=110%.  Equal to collateral / liabilities.
  Note that this the HF for the _bidding_ bot.  The collateral and liabilities are
  transfered directly to the bidding bot, so the HF of the bot's account
  needs to be high enough to handle that.  That means it should already have significant
  collateral in the bank.  The HF is calculated including the fillers existing deposits.
* example (v1):
  https://github.com/script3/auctioneer-bot/blob/main/example.config.json
* for auctions, lot values move 0.005 (0.5 basis points) per block for the first 200 blocks,
  then bid value moves down 0.006 after that.  So any change less than that will not
  affect the block the bidder goes for.

liquidation fills:

https://stellar.expert/explorer/public/tx/7bbaf8aabede72a3fb8fa8aea0f3b2bfc0e97d35a239daa8b64f016f903be444
request_type: 6

In the UI, the "auctions" tab will list the final value the auction was filled at.

It is possible to run the auction bot against a public RPC like
`soroban-rpc.creit.tech`, but you will quickly run into rate limiting
issues.

## creating BLNT v3 interest auctions

    ~/work/script3/blend/blend-utils/auction/new-interest-v3.sh

Calls `new_auction` (auction_type 2 = interest auction, percent 100) on the
BLNT v3 pool CACSQWCMKG45TUHCQ3LXHOB7YEEJH4W376ZHQPXH2IZ3TE4NJHFZMCY7 on
mainnet, signed by the `xbull` key, with a lot of 3 reserve assets (v3 lots
max out at 4).  Output goes to auction.log.

If it fails with Error #1228 (not enough interest accrued yet), it prints
each lot asset's accrued backstop_credit.  A single backstop tier's share of
the lot has to be worth at least $20 before an auction can be created.
Other errors: #1200 = bad request (wrong user / percent != 100),
#1227 = invalid interest auction.

Run it in a loop until an auction gets created:

    ( while true ; do date ; ./new-interest-v3.sh ; sleep 300 ; done ) 2>&1 | tee log

new-interest.sh is the Blend v2 equivalent (ybx v2 and other v2 pools, lots
of up to 5 assets).
